# vaz-torg-1c
Выпускная аттестационная работа: разработка конфигурации 1С для автоматизации торгового предприятия ООО «ВазТорг» с нуля.
# Конфигурация «Учет торгового предприятия» (ООО «ВазТорг»)
Разработано на платформе **1С:Предприятие 8.3** (Учебная версия).

## 🎯 Описание проекта
Конфигурация создана с нуля и предназначена для комплексной автоматизации оперативного, складского и финансового учета группы торговых предприятий.

---

## 🛠 Реализованный функционал и архитектура

### 1. Подсистемы и интерфейс
Проект разделен на 4 блока для удобства пользователей:
* **Закупки** — блок для снабжения и работы с поставщиками.
* **Продажи** — блок для менеджеров коммерческого отдела.
* **НСИ** —  управление нормативно-справочной информацией.
* **Отчеты** — блок для отчетов компании.

### 2. Объекты метаданных
* **Справочники (11 объектов):** Номенклатура, Контрагенты, Договоры, Организации, Расчетные счета, Сотрудники, Банки, Склады, Валюты, Должности, Пользователи.
* **Документы (7 объектов) и Журналы:**
  * Реализован полный цикл движения товаров и услуг: *ЗаказТоваров, ПоступлениеТоваровИУслуг, СчетНаОплату, РеализацияТоваровИУслуг, РеализацияТоваров, РеализацияУслуг, РегистрацияЦен, ВыпискаБанка*.
  * Созданы **Торгово-Закупочный журнал** и **Общий журнал** документов.
* **Регистры:**
  * **Регистры сведений (Периодические):** *ЦеныПродажи* (хранение истории стоимости номенклатуры), *КурсыВалют*.
  * **Регистры накопления:** *ОстаткиМатериала* (Тип: Остатки), *СтоимостьМатериала* (расчет себестоимости), *Взаиморасчеты* (дебиторская/кредиторская задолженность), *Продажи* (Тип: Обороты), *УчетУслуг* (Тип: Обороты).

### 3. Программирование и бизнес-логика (Встроенный язык 1С)
* Реализовано клиент-серверное взаимодействие с четким разделением контекста.
* Написаны алгоритмы проведения документов по регистрам накопления и сведений в модулях объектов (обработчик `ОбработкаПроведения`).
* Разработаны механизмы динамического пересчета цен, сумм и валют при изменении данных в табличных частях.
* Использован **Язык запросов 1С** для расчета себестоимости списания товаров и контроля отрицательных остатков на складах.
* Реализована функция вывода суммы документа прописью для печатных форм.

### 4. Сервисные возможности и отчетность
* Добавлена внешняя обработка **«ЗагрузкаДанныхИзExcel»** для наполнения справочников.
* Создана система отчетов: *ОстаткиТоваров, Доходы, СпискиКонтрагентов, СписокНоменклатуры, НоменклатураВДокументах, ДокументыКонтрагентов, НоменклатураКонтрагента*.
* Настроены **Роли и права доступа** для работы пользователей.
