# Конфигурация «Учет торгового предприятия»
Разработано на платформе **1С:Предприятие 8.3** 

## 🎯 Описание проекта
Конфигурация создана с нуля и предназначена для автоматизации оперативного, складского и финансового учета предприятия.

---

## 🛠 Реализованный функционал

### 1. Подсистемы и интерфейс
Проект разделен на 4 блока для удобства пользователей:
* **Закупки** — блок для снабжения и работы с поставщиками.
* **Продажи** — блок для менеджеров коммерческого отдела.
* **НСИ** —  управление нормативно-справочной информацией.
* **Отчеты** — блок для отчетов компании.

### 2. Объекты метаданных
* **Справочники (11 объектов):** Номенклатура, Контрагенты, Договоры, Организации, Расчетные счета, Сотрудники, Банки, Склады, Валюты, Должности, Пользователи.
* **Документы (7 объектов) и Журналы:**
  * Реализован цикл движения товаров и услуг: *ЗаказТоваров, ПоступлениеТоваровИУслуг, СчетНаОплату, РеализацияТоваровИУслуг, РеализацияТоваров, РеализацияУслуг, РегистрацияЦен, ВыпискаБанка*.
  * Созданы **Торгово-Закупочный журнал** и **Общий журнал** документов.
* **Регистры:**
  * **Регистры сведений:** *ЦеныПродажи*, *КурсыВалют*.
  * **Регистры накопления:** *ОстаткиМатериала*, *СтоимостьМатериала*, *Взаиморасчеты*, *Продажи*, *УчетУслуг*.

### 3. Что реализовано на встроенном языке 1С
* Реализовано клиент-серверное взаимодействие с разделением контекста.
* Написаны алгоритмы проведения документов по регистрам накопления и сведений в модулях объектов.
* Механизмы динамического пересчета цен, сумм и валют при изменении данных в табличных частях.
* Механизм для расчета себестоимости списания товаров и контроля отрицательных остатков на складах.
* Функция вывода суммы документа прописью для печатных форм.

### 4. Сервис и отчеты
* Добавлена внешняя обработка **«ЗагрузкаДанныхИзExcel»** для наполнения справочников.
* Создана система отчетов: *ОстаткиТоваров, Доходы, СпискиКонтрагентов, СписокНоменклатуры, НоменклатураВДокументах, ДокументыКонтрагентов, НоменклатураКонтрагента*.
* Настроены **Роли и права доступа** для работы пользователей.
